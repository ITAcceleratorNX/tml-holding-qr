# TMK Holding - QR-лендинг для форума

Короткая имиджевая страница TMK Holding для перехода по QR-коду со стенда.
Mobile-first, статическая сборка на **Astro** - на выходе чистый HTML/CSS,
JS ≈ 1 КБ. Формы заявки нет: все основные CTA ведут в WhatsApp
на **+7 702 339 1998** с заранее заполненным сообщением.

## Команды

```bash
npm install
npm run dev      # локальная разработка → http://localhost:4321
npm run build    # статическая сборка в dist/
npm run preview  # посмотреть готовую сборку → http://localhost:4173
```

## Деплой

`dist/` - обычная статика, кладётся на любой хостинг.

* **Vercel:** импортировать репозиторий, framework preset - Astro, больше ничего настраивать не нужно.
* **Netlify / Cloudflare Pages:** build command `npm run build`, publish directory `dist`.
* Перед публикацией поменяйте `site` в `astro.config.mjs` на боевой домен -
  от него строятся canonical и og:image.

QR-код со стенда должен вести на опубликованный URL этой страницы.

## Анимация появления

Скрипт раздаёт каждому элементу задержку в `--delay`, дальше всё делает CSS -
анимируются только `opacity` и `transform`, их считает композитор, поэтому
кадры не проседают и на слабом телефоне.

* Контейнер с `data-stagger` раздаёт детям волну: `data-base` - пауза до начала,
  `data-step` - шаг между элементами, `data-mod` - через сколько штук счёт
  сбрасывается (у сетки логотипов `4`, чтобы плитки появлялись построчно,
  а не «хвостом» на секунду).
* Отдельным элементам задержка ставится атрибутом `data-delay` в миллисекундах.
* Крупные цифры (`.stat__n`, `.mini b`) досчитываются от нуля за 720 мс.
  Значения без одного явного числа (`24/7`) и всё меньше десяти пропускаются.
* Фото в герое выходит из зума 1.06 → 1 за 1,6 с.
* При `prefers-reduced-motion: reduce` всё это выключается: блоки сразу видны,
  цифры не считаются, ховер-подъёмы сняты.

Убрать анимацию целиком - удалить блоки 1–3 из `<script>` в `src/pages/index.astro`
и класс `.r` в `src/styles/global.css`.

## Производительность

* Первая загрузка: **~310 КБ**, 24 запроса, HTML со встроенным CSS одним файлом.
* Логотипы и фото - WebP, ниже первого экрана - `loading="lazy"` с заданными
  размерами (нет сдвигов вёрстки).
* Внешние ссылки открываются в новой вкладке с `rel="noopener noreferrer"`.

## Доступность

Поддержаны `prefers-reduced-motion`, `prefers-reduced-transparency`,
`prefers-contrast: more`, safe-area на iPhone, зоны нажатия ≥ 44 px,
видимый фокус с клавиатуры, ссылка «перейти к содержимому».
