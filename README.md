# TMK Holding - QR-лендинг для форума

Короткая имиджевая страница TMK Holding для перехода по QR-коду со стенда.
Mobile-first, статическая сборка на **Astro** - на выходе чистый HTML/CSS,
JS ≈ 1 КБ. Формы заявки нет: все основные CTA ведут в WhatsApp
на **+7 702 339 1998** с заранее заполненным сообщением.

## Команды

```bash
npm install
npm run dev      # локальная разработка → http://localhost:4321
npm run build    # статическая сборка в dist/
npm run preview  # посмотреть готовую сборку → http://localhost:4173
```

## Деплой

`dist/` - обычная статика, кладётся на любой хостинг.

* **Vercel:** импортировать репозиторий, framework preset - Astro, больше ничего настраивать не нужно.
* **Netlify / Cloudflare Pages:** build command `npm run build`, publish directory `dist`.
* Перед публикацией поменяйте `site` в `astro.config.mjs` на боевой домен -
  от него строятся canonical и og:image.

QR-код со стенда должен вести на опубликованный URL этой страницы.

## Дизайн

С обновления от 11.09.2026 палитра и шрифт сняты не с презентации, а с
живого сайта **[tmk-limited.com](https://tmk-limited.com)** - по прямому
требованию ПМ синие/голубые акценты убраны, всё приведено к фирменному стилю
основного сайта.

| Роль | Цвет |
| --- | --- |
| Основной тёмно-синий | `#2B3F58` |
| Золото (акцент, кнопки) | `#BDA57E` |
| Самый тёмный (футер) | `#111923` |
| Светлая секция | `#EEF0F2` |

Акценты компаний - только эти два цвета вперемешку (навy / золото / навy /
золото), без произвольных цветов на каждое направление: Techno Horizon,
Metropolis Property и CoCo's - тёмно-синий, Extra Space и Qaitadan - золото.
При нечётном числе карточек последняя не висит у левого края, а встаёт
по центру ряда в ширину колонки. Сами
карточки одинаковые, белые, различаются полосой сверху, плашкой категории
и кнопкой - так же, как карточки направлений на самом tmk-limited.com.

Все углы - острые (`border-radius: 0`), без теней-«свечения» на кнопках:
это дословно то, как выглядит сайт-источник, и заодно то, что отличает
страницу от типового шаблона с round-everything и неоновыми градиентами.

**Шрифт.** У сайта - платный вебшрифт **Gilroy** (лицензия MyFonts,
привязана к домену tmk-limited.com; те файлы нельзя законно скопировать на
другой домен). Вместо копирования подключён **Manrope** - ближайший по
рисунку бесплатный аналог (OFL, можно самостоятельно хостить где угодно),
вариативный, 400–800 в одном файле на кодировку, latin + cyrillic ≈ 38 КБ.
Если у холдинга есть лицензия Gilroy и на домен QR-лендинга - можно
подставить настоящий Gilroy: заменить два файла в
`public/assets/fonts/` и переименовать `font-family` в
`src/styles/global.css`.

### Арт карточек

У карточки может быть картинка-шапка (`art` в `src/data/site.js`); её
собственные размеры задаются рядом - `artW` / `artH`, по умолчанию 860×1040.
Полоса выводится через `object-fit: cover` и штатно затухает в белый на
нижних 45 % - значит важное в картинке должно лежать выше ~62 % высоты.

Арт CoCo's собирается из фирменного логотипа скриптом
`tools/cocos-art.mjs` (пропорция 2,78:1 - при ней вертикальный кроп ничего
не режет, а на узком экране остаются центральные ~70 % ширины):

```bash
node tools/cocos-art.mjs
cwebp -q 82 public/assets/img/brand/cocos-art.png -o public/assets/img/brand/cocos-art.webp
rm public/assets/img/brand/cocos-art.png
```

## Анимация появления

Скрипт раздаёт каждому элементу задержку в `--delay`, дальше всё делает CSS -
анимируются только `opacity` и `transform`, их считает композитор, поэтому
кадры не проседают и на слабом телефоне.

* Контейнер с `data-stagger` раздаёт детям волну: `data-base` - пауза до начала,
  `data-step` - шаг между элементами, `data-mod` - через сколько штук счёт
  сбрасывается (у сетки логотипов `4`, чтобы плитки появлялись построчно,
  а не «хвостом» на секунду).
* Отдельным элементам задержка ставится атрибутом `data-delay` в миллисекундах.
* Крупные цифры (`.stat__n`, `.mini b`) досчитываются от нуля за 720 мс.
  Значения без одного явного числа (`24/7`) и всё меньше десяти пропускаются.
* Фото в герое выходит из зума 1.06 → 1 за 1,6 с.
* При `prefers-reduced-motion: reduce` всё это выключается: блоки сразу видны,
  цифры не считаются, ховер-подъёмы сняты.

Убрать анимацию целиком - удалить блоки 1–3 из `<script>` в `src/pages/index.astro`
и класс `.r` в `src/styles/global.css`.

## Производительность

* Первая загрузка: **~360 КБ**, 25 запросов, HTML со встроенным CSS одним файлом.
* Логотипы и фото - WebP, ниже первого экрана - `loading="lazy"` с заданными
  размерами (нет сдвигов вёрстки).
* Внешние ссылки открываются в новой вкладке с `rel="noopener noreferrer"`.

## Доступность

Поддержаны `prefers-reduced-motion`, `prefers-reduced-transparency`,
`prefers-contrast: more`, safe-area на iPhone, зоны нажатия ≥ 44 px,
видимый фокус с клавиатуры, ссылка «перейти к содержимому».
